# MyTelescope skills — all categories

Each zip in this folder is a self-contained bundle of MyTelescope skills tuned for one marketing job.

Every category zip includes:
- mytelescope-core-SKILL.md (system rules, brand voice, MCP workflow)
- mytelescope-orchestrator-SKILL.md (routes between skills in multi-step flows)
- The category-specific skills

## Categories

- **product-marketing.zip** — product strategy, pricing, where to invest
- **growth-marketing.zip** — paid, performance, GTM
- **content-creation.zip** — write, plan, structure
- **seo.zip** — search visibility (organic + AI)
- **brand-marketing.zip** — identity, positioning, voice, perception
- **market-research.zip** — analytical understanding of markets
- **trend-signals.zip** — tracking change over time
- **ai-visibility.zip** — AI search optimisation

## How to install

Pick the category that matches your job. Unzip it. In Claude, go to Settings → Capabilities → Customize and upload each .md file. Make sure the MyTelescope MCP connector is installed (Settings → Connectors → Custom connectors).
