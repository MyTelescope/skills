# MyTelescope skills — all categories

Each zip is a self-contained bundle for one marketing job.

## Folder structure inside each zip

- SKILL.md — entry point (orchestrator, cross-references other skills)
- mytelescope-core-SKILL.md — system rules and brand voice
- Category-specific skill files

## How to install

Unzip the category you need. In Claude → Settings → Capabilities → Customize, upload each .md. Make sure the MyTelescope MCP connector is installed.
