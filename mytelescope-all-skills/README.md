# MyTelescope skills — all skills in one bundle

Every MyTelescope skill in a single folder. Install all of them at once and your Claude agent has the full marketing stack.

## How to install

1. Unzip this folder.
2. In Claude, go to Settings → Capabilities → Customize.
3. Upload each .md file in this folder.
4. Make sure you have the MyTelescope MCP connector installed (Settings → Connectors → Custom connectors).

## What's inside

- SKILL.md — entry point (orchestrator, routes between skills)
- mytelescope-core.skill.md — system rules, brand voice, MCP workflow
- brand-rendering.skill.md — visual + vocabulary rules (typography, colors, charts, formatting). Load in parallel with any skill that produces visual output, charts, or numerical text
- strategic-brief.skill.md — write a strategic brief
- product-thinking.skill.md — sharpen product thinking
- pricing-distribution.skill.md — decide pricing and distribution
- category-portfolio.skill.md — audit a category portfolio
- brand-tracking.skill.md — track your brand
- content-strategy.skill.md — plan your content
- copywriting.skill.md — write copy that lands
- campaign-activation.skill.md — activate a campaign
- ai-visibility.skill.md — get AI visibility
